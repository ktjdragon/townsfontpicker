# townsfontpicker
A Python script for browsing characters form Fujitsu FM TOWNS font file.

Supported font file format: FM TOWNS *.FNT and FontCity bitmap *.Dnn files (stored in \\FJ2\\FONT directory of Towns System Software V2.1 CD).

usage: python townsfontpicker.py fontfilename

The format of each font file is described in https://ktjdragon.com/nb/towns/towns_font_file_format (Japanese).
